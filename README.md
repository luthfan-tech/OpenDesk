# OpenDesk

OpenDesk is an open-source smart desk controller designed to help students
create a more comfortable and focused study environment.

## What it does
- Monitors room temperature, humidity, and light
- Controls a lamp or fan
- Shows live readings on a web dashboard
- Allows manual control from a browser

## Why I built it
I wanted to learn 3D modelling, electronics, embedded systems,
and full-stack development through one practical project.

## Tech stack
- Fusion 360
- ESP32 / Raspberry Pi Pico W
- C++ / MicroPython
- HTML, CSS, JavaScript
- GitHub for documentation and version control
